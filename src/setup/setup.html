Welcome

GoCD Lens reads your pipelines from the GoCD REST API and draws its own dashboard, so it keeps working when the GoCD web UI is restarting, half-loaded, or has decided your pipelines do not exist. Connect a server below and you are done.

Is it GoCD, or is it me?

Checks the GoCD API directly to verify whether your pipelines are responding as expected. If the GoCD UI isn't responding but the API is, your pipelines are still running normally. Feel free to keep using GoCD Lens to monitor them.
